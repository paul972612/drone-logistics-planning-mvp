Ansicht

„Maßstäblich“ = echte Meter, gleiche Skala wie die Flughöhe. OSM-Höhen: OSM-Tag, sonst Geschosse × 3 m + 1 m, sonst Typ-Standard (z. B. Garage 3 m, Einfamilienhaus 8 m, Mehrfamilienhaus 14 m, Krankenhaus 18 m) – die meisten Höhen sind daher geschätzt. Zensus-Variante: nur Wohngebäude, 13+ WE pauschal 24 m.

Routen

Durchgezogen = optimale Route (Restriktionen + Bevölkerungsdichte), gestrichelt = SORA-Alternative (niedrigere Streckenklasse, max. 1,5× so lang wie die optimale Route), grau gestrichelt = Luftlinie.
EW = Einwohner im Überflugkorridor (≈115 m), Route / Luftlinie. iGRC = SORA-Bodenrisikoklasse (Drohne ≤ 3 m, ≤ 35 m/s, max. Dichte im Fußabdruck) für Luftlinie / Route / Start-Landezone (≈350 m). Q = Querungen von Trassenpuffern. H = höchstes OSM-Gebäude unter der Route (m; Höhe aus Tag, Geschossen oder Typ-Standard). Flugzeit bei 60 km/h.

Verteilungsbilanz Überflug
